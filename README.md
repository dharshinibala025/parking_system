# 🅿️ ParkEase — Online Parking Slot Booking System

A modern, full-stack online parking slot booking and management application built with **Next.js 15**, **Node.js Express REST API**, and **MongoDB Atlas**.

---

## 🚀 Live Production Links

- **Frontend App (Vercel)**: [https://frontend-pi-orpin-72.vercel.app](https://frontend-pi-orpin-72.vercel.app)
- **Backend API (Render)**: [https://parking-system-i0zm.onrender.com](https://parking-system-i0zm.onrender.com)

---

## ✨ Features

- 📍 **Real-time Parking Slot Availability**: Check vacant and occupied slots.
- 🚗 **Vehicle & Spot Booking**: Reserve spots dynamically with instant confirmation.
- 📱 **QR Code Ticket Generation**: Scan QR codes for seamless entry & exit.
- 🔒 **User & Admin Roles**: JWT authentication with admin dashboards and revenue reports.
- ⚡ **Optimized Performance**: Next.js App Router, Tailwind CSS, & Mongoose schema models.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js 15, React 19, Tailwind CSS, Lucide Icons, Shadcn UI
- **Backend**: Node.js, Express.js, MongoDB Atlas, Mongoose, JWT, BcryptJS
- **Hosting**: Vercel (Frontend), Render (Backend)
